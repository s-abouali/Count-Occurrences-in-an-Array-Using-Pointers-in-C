# Count Occurrences in an Array Using Pointers in C

## Description

This program counts how many times a given integer appears in an array using a pointer.

## Objectives

* Understand pointer manipulation.
* Traverse an array using a pointer.
* Count occurrences of a specific value.
* Use functions and conditional statements.

## Example

Input:

Array: 4 7 4 2 4 9
Value to search for: 4

Output:
Number of occurrences of 4: 3
